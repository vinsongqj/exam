A tree is an undirected connected graph with no cycles.

You are given an undirected graph that started as a tree with `n` nodes labeled from `1` to `n`, but one extra edge was added. As a result, the graph contains exactly one cycle.

The graph is represented by an array `edges` of length `n`, where `edges[i] = [u, v]` represents an edge between vertices `u` and `v`.

Write a function `redundant_link` that returns an edge that can be removed so that the resulting graph is a tree of `n` nodes.
If there are multiple answers, return the edge that appears last in the given `edges` list.

Allowed functions: None

Function signature

def redundant_link(edges: list[list[int]]) -> list[int]: 

Examples
Input
redundant_link([[1, 2], [1, 3], [2, 3]])
Output
[2, 3]
Input
redundant_link([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]])
Output
[1, 4]
Input
redundant_link([[1, 4], [3, 4], [1, 3], [1, 2], [4, 5]])
Output
[1, 3]
